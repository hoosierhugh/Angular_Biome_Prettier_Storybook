# Angular (22+) + Biome + Prettier + Storybook Set Up

Repo for my Angular 22+, Storybook 10.6+, Biome, and Prettier set up that goes with my YouTube video, https://www.youtube.com/watch?v=9sJB_bxNF5Q.

## Why Biome + Prettier?

If you want to avoid ESLint hell, this is a working setup for Angular 22+ projects that uses Biome for linting/formatting TS/JS/JSON/CSS and Prettier for formatting proprietary Angular html templates with the string interpolation (the double curly braces {{}}), just like in Vue.js with the Vue templates.
